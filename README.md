# Odin Etch-a-Sketch

Etch-a-Sketch project for The Odin Project's Foundations course. A grid of
squares that you draw on by moving the mouse over them, built with HTML, CSS
and JavaScript.

## Features

- 16 x 16 grid by default
- "New grid" asks for a size from 1 to 100 and rebuilds the grid at the same
  total size
- "Clear" wipes the drawing
- Three drawing modes: black, rainbow (random colors) and darken (each pass
  adds 10% black)
